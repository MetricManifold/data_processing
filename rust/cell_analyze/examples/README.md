# `cell_analyze` runnable examples

Each `.rs` file in this tree is a standalone program demonstrating one
piece of the analysis pipeline. They use the `cell_analyze` library
(`src/lib.rs`) directly — no TOML, no aggregator pipeline, just one
observable per example. For full studies (TOML-driven figures + raw
JSON), use the `cell_analyze study` subcommand.

## Running

From the crate root (`rust/cell_analyze/`):

```
cargo run --release --example <name>
cargo run --release --example <name> -- <run_dir>
```

With no positional arg, examples default to
`results/local_test/100c_rho90_ctrl/run_01` (the local short t=1000τ run
generated by the smoke test). Pass an alternative `<run_dir>` as the
sole positional arg to point at any other directory containing
`trajectory.txt` and (optional) `checkpoint.bin`.

The runnable binaries live at `target/release/examples/<name>.exe`
after `cargo build --release --examples`.

## Output format

Per-observable examples print the observable's full output as
pretty-printed JSON, with arrays longer than ~10 elements truncated to
first-5 / last-5 plus `... (N elided) ...` to keep the console
readable. The full struct is still computed; only the print is
abbreviated.

`palmieri_validation` prints a tabular soft-vs-ctrl comparison plus the
headline ratio.

## Generating fresh test data

If `results/local_test/100c_rho90_*/run_01/` doesn't exist, generate
it from the repo root:

```
.\cpp\simulation\build\bin\cell_sim.exe -n 100 --confluence 0.90 \
    --radius 49 -t 1000 --tau 10000 --v-A 0.01 \
    --gamma 1.5 --seed 42 --polarity-seed 42 \
    --trajectory-samples 200 --print-interval 1000 \
    -o results/local_test/100c_rho90_ctrl/run_01

.\cpp\simulation\build\bin\cell_sim.exe -n 100 --confluence 0.90 \
    --radius 49 -t 1000 --tau 10000 --v-A 0.01 \
    --gamma "1.5:cell0:0.35" --seed 42 --polarity-seed 42 \
    --trajectory-samples 200 --print-interval 1000 \
    -o results/local_test/100c_rho90_soft/run_01
```

Both finish in ~30 seconds on an H100. For Palmieri-comparable D_eff
ratios you want t = 200τ ≈ 2,000,000 sim units (much longer).
